---
title: Keyboard shortcuts
description: Every shortcut in the editor. On a Mac, use Cmd for Ctrl and Option for Alt.
---

| Action | Shortcut |
|--------|----------|
| Bold, italic, underline | `Ctrl+B`, `Ctrl+I`, `Ctrl+U` |
| Strikethrough | `Ctrl+Shift+X` |
| Superscript, subscript | `Ctrl+.`, `Ctrl+,` |
| Clear formatting | `Ctrl+\` |
| Undo, redo | `Ctrl+Z`, `Ctrl+Shift+Z` or `Ctrl+Y` |
| Cut, copy, paste | `Ctrl+X`, `Ctrl+C`, `Ctrl+V` |
| Paste without formatting | `Ctrl+Shift+V` |
| Normal text | `Ctrl+Alt+0` |
| Heading 1 to 6 | `Ctrl+Alt+1` to `Ctrl+Alt+6` |
| Bulleted, numbered list | `Ctrl+Shift+8`, `Ctrl+Shift+7` |
| Increase, decrease list level | `Tab`, `Shift+Tab` (inside a list) |
| Next, previous table cell | `Tab`, `Shift+Tab` (inside a table). `Tab` in the last cell adds a row |
| Increase, decrease indent | `Ctrl+]`, `Ctrl+[` |
| Align left, center, right, justify | `Ctrl+Shift+L`, `E`, `R`, `J` |
| Insert link | `Ctrl+K` |
| Insert footnote | `Ctrl+Alt+F` |
| Page break | `Ctrl+Enter` |
| Find | `Ctrl+F` |
| Find and replace | `Ctrl+H` |
| Print | `Ctrl+P` |
| Save | `Ctrl+S`, when you pass `onSave` |
| New line inside a paragraph | `Shift+Enter` |

`Tab` only moves between cells or changes list levels when the caret is in a table or a list, so keyboard users can still tab out of the editor.
